QUICKDROP

J.A.R.V.I.S.-style file beam — device se device, seedha

Ye naam doosre devices ko peer-list me dikhega, taaki pata chale kaunsa device kiska hai.

Ek naya room-code banega. Wahi code doosre device par "Room Join Karo" me daal ke enter karna hai — chahe wo kisi bhi WiFi/mobile-data par ho.

Yahi code jo room banane wale ne share kiya hai — dono taraf same code hona chahiye.

Koi code nahi chahiye. Sirf same WiFi/hotspot par jitne devices ye site kholenge, wo apne-aap ek doosre ko dikh jayenge. Alag network (jaise ek WiFi pe, ek mobile data pe) walon ke liye ye kaam nahi karega — uske liye "Room Join Karo" wala option use karo.
